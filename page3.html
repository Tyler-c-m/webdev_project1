Database Administrator

Description

Provides technical support for the development, implementation and maintenance of an internal database. Maintains policies and procedures for ensuring database security and integrity. Implements data models, database designs, data access and table maintenance codes. Resolves database performance, capacity, replication and distribution issues. Relies on knowledge and professional discretion to plan and achieve goals. Works under general supervision and usually reports to a supervisor, though some ingenuity and flexibility is required.

Responsibilities

System Security Planning

Database Administrators and Architects are tasked with planning, updating, and implementing security measures to protect information from accidental damage or unauthorized attacks and modifications. Some of the methods these tasks are done is from supervising new products or updates to systems along with developing guidelines for the use of software acquisition and to protect vulnerable information. From these tasks given, they are able to evaluate and recommend hardware and software technologies to improve database performance.

Coding

Database Administrators code database descriptions to management systems along with entering codes to monitor performance and create production databases.

Assertive Roles

When it comes tomore assertive roles, Administrators are to specify users and their levels of access within databases, train said users and answer questions, and provide technical support to clients to staff.

  • Attention to Detail
  • Problem-Solving Skills
  • Strong Teamwork
  • Adaptability
